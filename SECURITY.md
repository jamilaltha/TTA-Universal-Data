# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in D10Z-TTA, please report it responsibly:

1. **DO NOT** open a public GitHub issue
2. Email: jamil@d10z.org with subject "SECURITY: [brief description]"
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 1 week
- **Resolution target**: Within 30 days for critical issues

## Scope

This policy covers:
- The D10Z Python package
- Official documentation
- GitHub Actions workflows
- Data integrity in the repository

## Out of Scope

- Third-party dependencies (report to respective projects)
- Theoretical disagreements (use scientific discussion issues)

## Recognition

Security researchers who report valid vulnerabilities will be acknowledged in our SECURITY.md unless they prefer to remain anonymous.
